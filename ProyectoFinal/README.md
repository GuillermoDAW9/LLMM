# ProyectoXML

Aplicación web que permite realizar tests cargados desde documentos XML validados con DTD.

## Funcionalidades
- Preguntas tipo test
- XML validado con DTD
- Selector de idioma (ES/EN)
- Reloj
- Puntuación

## Cómo usar
Abrir index.html en un navegador.
